BoroOCR — macOS 15+

1. BoroOCR.app → Applications руу чирнэ.
2. Applications дотроос BoroOCR нээнэ. Python суулгахгүй.
3. Apple notarization-гүй build тул хаагдвал System Settings → Privacy & Security → Open Anyway сонгоно.
4. Хэсэг сонгох дарна. Screen Recording / Screen & System Audio Recording хэсэгт BoroOCR-д зөвшөөрөл өгөөд бүрэн хааж дахин нээнэ.
5. Үндсэн дэлгэцийн асуулт + сонголтуудыг хүрээлнэ. BoroOCR цонхоо хүрээнээс гадна байрлуулна.
6. Хяналт эхлүүлэх дарж өөрийн Groq API key оруулна.

API key зөвхөн санах ойд байна; програм дахин нээхэд дахин оруулна.
Сонгосон хэсгийн зураг Groq API руу илгээгдэнэ. Интернэт, API эрх шаардлагатай.
Зогсоох нь шинэ хүсэлтийг зогсооно. Өмнө илгээгдсэн хүсэлт дуусаж болно.
Хариултын түүх програм нээлттэй үед хадгалагдана.
Үндсэн дэлгэц дэмжинэ; олон дэлгэц дамнасан сонголт дэмжихгүй.
